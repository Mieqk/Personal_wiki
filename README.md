# Personal Wiki

Локальная база знаний, превращающая папку с Markdown-файлами в статический веб-сайт в стиле Notion/Obsidian. Полностью работает офлайн, без облачных зависимостей.

## Особенности

- 📝 **Markdown + Вики-ссылки**: Поддержка `[[ссылок]]` между заметками
- 🔍 **Полнотекстовый поиск**: Быстрый поиск через SQLite FTS5
- 🕸️ **Граф связей**: Визуализация связей между заметками (D3.js)
- 🏷️ **Теги и метаданные**: YAML frontmatter для организации контента
- 🌙 **Тёмная тема**: Минималистичный дизайн, адаптивная вёрстка
- ⚡ **Статическая генерация**: Мгновенная загрузка страниц

## Требования

- Python 3.11+
- pip (менеджер пакетов Python)

## Использование

### Создание заметок

Создайте папку с вашими `.md` файлами. Пример структуры:

```markdown
---
title: Моя заметка
tags: [идеи, проект]
created: 2026-08-16
---

# Заголовок

Это пример заметки со ссылкой на [[Другая заметка]].

- [x] Задача 1
- [ ] Задача 2

```python
print("Код тоже поддерживается")
```
```

### Команды CLI

#### 1. Сборка сайта

Сгенерировать статический сайт из папки с заметками:

```bash
python main.py build --source notes/ --output output/
```

Параметры:
- `--source`: Папка с исходными `.md` файлами (по умолчанию: `notes/`)
- `--output`: Папка для сгенерированного сайта (по умолчанию: `output/`)
- `--incremental`: Режим инкрементальной сборки (только изменённые файлы)

#### 2. Запуск локального сервера

Собрать сайт и запустить локальный веб-сервер для просмотра:

```bash
python main.py serve --source notes/ --port 8000
```

Параметры:
- `--source`: Папка с исходными `.md` файлами
- `--port`: Порт для локального сервера (по умолчанию: `8000`)

После запуска откройте в браузере: `http://localhost:8000`

#### 3. Помощь

Просмотр доступных команд:

```bash
python main.py --help
python main.py build --help
python main.py serve --help
```

## Синтаксис

### Вики-ссылки

Используйте двойные квадратные скобки для ссылок между заметками:

```markdown
[[Название заметки]]
[[Другая заметка|Текст ссылки]]  # Ссылка с кастомным текстом
```

Если заметка не найдена, ссылка будет помечена как "битая" (красный цвет).

### YAML Frontmatter

В начале файла можно указать метаданные:

```yaml
---
title: Заголовок страницы
tags: [тег1, тег2, тег3]
created: 2026-08-16
updated: 2026-08-17
---
```

Поддерживаемые поля:
- `title`: Заголовок страницы (если не указан, используется имя файла)
- `tags`: Список тегов для категоризации
- `created`: Дата создания
- `updated`: Дата последнего изменения

### Markdown

Поддерживается весь стандартный синтаксис Markdown:
- Заголовки (`#`, `##`, `###`)
- Списки (маркированные, нумерованные, чекбоксы)
- Таблицы
- Кодовые блоки с подсветкой синтаксиса
- Изображения (`![alt](path/to/image.png)`)
- Цитаты, жирный текст, курсив и т.д.

## Поиск

Поиск работает через SQLite FTS5 (Full-Text Search):
- Индексируются заголовки и содержимое всех заметок
- Подсветка найденных совпадений в результатах
- Поиск по тегам

## Граф связей

На странице `/graph.html` отображается интерактивный граф:
- Узлы — заметки
- Рёбра — вики-ссылки между заметками
- Клик по узлу открывает соответствующую заметку
- Масштабирование и перемещение мышью

## Темы оформления

По умолчанию включена тёмная тема. Для изменения стилей отредактируйте `static/style.css`.

## Отладка

При ошибках парсинга файл пропускается, ошибка логируется в консоль. Проверьте:
- Корректность YAML frontmatter (отступы, синтаксис)
- Наличие закрывающих элементов в Markdown
- Права доступа к папкам
